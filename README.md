# Impacto de las redes sociales en la vida.
Impacto de las Redes Sociales en la Vida de los Estudiantes
Autor: Guadalupe Hernández
Curso: Herramientas básicas para el Análisis de Datos

Descripción del proyecto
Este proyecto analiza la relación entre el uso de las redes sociales y distintos aspectos del bienestar estudiantil, como el nivel de estrés, la calidad del sueño, la salud mental y el rendimiento académico. Para ello, se trabajó con un conjunto de datos que contiene información sobre hábitos de uso de plataformas digitales, características académicas y variables relacionadas con el bienestar de los estudiantes.

Se realizó un proceso de limpieza y preparación de datos utilizando Python y Pandas, que incluyó la identificación de valores faltantes, la revisión de registros duplicados, el tratamiento de variables categóricas y la detección de valores atípicos mediante el método IQR. Posteriormente, se desarrolló un análisis exploratorio para identificar patrones, tendencias y relaciones entre las variables.

Las principales preguntas abordadas fueron: la relación entre las horas de uso de redes sociales y el nivel de estrés, el impacto del uso nocturno en la calidad del sueño, las plataformas más utilizadas según el nivel académico y la variación del rendimiento académico en función del tiempo de uso de redes sociales.

Finalmente, se construyó un dashboard interactivo en Power BI con indicadores clave (KPIs), filtros dinámicos y visualizaciones que permiten explorar los resultados de forma intuitiva y facilitar la toma de decisiones basada en datos.
