# Impacto-de-las-redes-sociales-en-la-vida
Este estudio analiza cómo el uso de las redes sociales se relaciona con el estrés, la calidad del sueño, la salud mental y el rendimiento académico de los estudiantes. A través del análisis exploratorio y visualizaciones interactivas, se identificaron patrones y diferencias entre distintos grupos de usuarios.
